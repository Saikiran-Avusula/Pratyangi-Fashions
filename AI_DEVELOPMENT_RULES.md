# AI Development Rules

Before coding, AI must read:
- 00_START_HERE.md
- ENVIRONMENT_SETUP.md
- PROJECT_REQUIREMENTS.md
- DESIGN_SYSTEM.md
- COMPONENT_ARCHITECTURE.md
- relevant animation specification
- ASSET_MANIFEST.md
- TEAM_RESPONSIBILITIES.md
- DEVELOPMENT_ROADMAP.md

## Rules
1. Work only within the developer's assigned responsibility.
2. Inspect existing code before creating new components.
3. Reuse existing components.
4. Do not invent colors, typography, spacing, assets or animations when specified.
5. Do not modify another developer's assigned feature without explicit approval.
6. Explain the implementation plan before large structural changes.
7. Run checks after implementation.
8. Do not declare a task complete until Definition of Done passes.
