# Definition of Done

A feature is complete only when:
- Figma layout matched
- Correct design tokens used
- Correct assets used
- Required interactions implemented
- Required animations implemented
- Desktop tested
- Tablet tested
- Mobile tested
- No broken images
- No console errors
- No TypeScript errors
- No unnecessary duplicated code
- Existing components reused
- Local build passes
- Git commit created
- Pull Request created
- Review completed
