# Project Requirements

## Project
PRATYANGI FASHIONS

## Current phase
Frontend implementation only.

## Frontend stack
- Next.js App Router
- React
- TypeScript
- CSS Modules
- Global CSS variables
- Framer Motion
- Lucide React
- React Hooks
- Mock data in TypeScript/JSON
- localStorage for demo persistence
- Git/GitHub

## Future phase
PHP APIs + MySQL + authentication + cart + wishlist + orders + payment integration.

Do not implement backend in the current frontend phase unless explicitly requested.

## Homepage scope
Header, Hero, Categories, New Arrivals, Wedding Collection, Festive Collections, Best Sellers, Customer Reviews, AI Try-On, Try-On Access, Exclusive Offers, Social/Community, Why Pratyangi Fashions, Newsletter and Footer.

## Quality goal
Match the approved Figma UI and prototype behavior as closely as practical, including responsive behavior and specified animations.
